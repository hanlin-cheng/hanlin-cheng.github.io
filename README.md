# HanLin 的技术博客

记录算法学习、机器人开发与工程实践中的思考和积累。

[访问博客](https://hanlin-cheng.github.io/) · [浏览全部笔记](https://hanlin-cheng.github.io/notes/index.html) · [笔记源仓库](https://github.com/hanlin-cheng/slam-study-note)

## 内容

博客涵盖数学基础、SLAM 与机器人、ROS 与中间件、C++ 开发、开发工具与工程实践、Linux 与嵌入式、Qt 开发、应用与杂记，以及论文阅读。

完整的分类目录与文章链接见[笔记目录](notes/README.md)。

## 阅读体验

- 首页随机展示 8 篇笔记，点击“换一批”发现更多内容。
- 支持全文搜索、分类浏览和文章目录。
- 笔记图片可点击放大，支持数学公式与表格。
- 适配手机阅读，支持浅色与深色模式。

## 技术栈

使用 [Hugo](https://gohugo.io/) 生成静态页面，基于 [Stack](https://github.com/CaiJimmy/hugo-theme-stack) 主题定制，外观参考 [Butterfly](https://butterfly.js.org/)，部署于 GitHub Pages。
